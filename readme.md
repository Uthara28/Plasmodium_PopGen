# Signatures of Multiple Merger Coalescence in Populations of *Plasmodium falciparum* Using SMC Methods

This repository contains data, scripts, and results for a study investigating **multiple-merger coalescent models (MMCs)** in the population genetics of *Plasmodium falciparum*. The project explores how MMC processes differ from standard **Kingman coalescent** models in describing the parasite’s **genetic diversity and transmission dynamics**.
